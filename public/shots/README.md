# Homepage screenshots

Drop these files here and the homepage shows them automatically. No code change is needed. Until a file exists, its panel shows a dashed "your screenshot goes here" frame.

| File | Shows |
| --- | --- |
| `web.png` | Pen & Paper in a browser, notes spread over a paper |
| `mac.png` | The menu-bar app's box floating over another app |
| `chrome.png` | The extension's pop-up over a web page |

`.webp`, `.jpg` and `.jpeg` work too (for example `web.webp`).

**Size:** 1600 × 1000 pixels (16:10). The frame crops to that shape, so a different shape gets trimmed at the edges.

**Tips**
- Use the same paper background and the light theme, so the three look like a set.
- Hide personal notes. Use a few made-up thoughts.
- Keep each file under about 400 KB (export as WebP or a compressed PNG).
- The page reads these files when it is built or served, so redeploy after adding them, or reload the dev server.
