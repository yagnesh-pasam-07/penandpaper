# Brand

The Pen & Paper logo: a ruled sheet with the fountain-pen nib (the app's favicon, `src/app/icon.svg`) finishing a handwritten line. Paper, ink and one red, the same tokens as `src/app/globals.css`.

| File | Use |
| --- | --- |
| `icon-red.svg` | The app icon. README header, social preview, anywhere it stands alone |
| `icon-light.svg` | App icon on paper (`#FAF8F3`) |
| `icon-dark.svg` | App icon for dark backgrounds (Ink theme) |
| `mark.svg` | The mark with no tile, on light backgrounds |
| `mark-dark.svg` | The mark with no tile, on dark backgrounds |
| `mark-mono.svg` | One colour: set `color` on the parent |

`docs/social-preview.png` (1280×640) is the card GitHub shows when the repo is shared. Upload it under the repo's **Settings → Social preview**.

Keep at least a quarter of the icon's width clear around it, and don't recolour the nib anything but red, ink or white.
